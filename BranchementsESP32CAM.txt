BRANCHEMENTS ESP8266 (PROGRAMMATEUR) VERS ESP32-CAM

1. NEUTRALISER L'ESP8266 (Le "pont") :
- Broche RST --> GND (sur le même ESP8266)

2. CONNEXIONS (ESP8266 vers ESP32-CAM) :
- VIN (5V) --> 5V
- GND      --> GND
- TX       --> U0T
- RX       --> U0R
(On ne croise pas TX et RX ici)

3. ACTIVER LE MODE FLASH (Sur l'ESP32-CAM) :
- GPIO 0   --> GND

⚠️ RAPPEL POST-FLASH :
Une fois le téléversement terminé ("Done uploading"), DÉBRANCHER le fil GPIO 0 -> GND et appuyer sur le bouton RESET de la caméra pour lancer le code.
